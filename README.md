This is my entry for the make.fun bounty "The Word You'd Delete From the Dictionary" — one word is erased from the dictionary forever. The word I chose to delete:

> supercalifragilisticexpialidocious

Why this one? Everyone recognises it instantly, it sounds funny on its own, and deleting the longest, most famous word that nobody can spell is the joke itself. The field is full of first picks like "moist", "queue" and "irregardless" — this one is fresh.

## Run it

```bash
python3 main.py
```

This writes the word to `/output/entry.txt` (validated to 1–77 UTF-8 characters, no surrounding whitespace, no newline, round-trip checked).
